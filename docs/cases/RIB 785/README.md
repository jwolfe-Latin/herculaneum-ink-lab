# RIB 785 Curated Case

## Permanent identity

- Official case ID: `RIB 785`
- Student-facing catalogue reference: `RIB 785`
- Permanent public case folder: `RIB 785`
- Development status: `in-development`
- Student-facing status: **In Development**

The space and capitalization in `RIB 785` are intentional. Application code
must not lowercase, hyphenate, slugify, or remove whitespace from the official
ID or public folder name.

## Permanent files

- Browser source image: `public/cases/RIB 785/source.png`
- Curated metadata: `src/content/curated/RIB 785/case.ts`
- Preserved instructor intake: `case-intake/RIB 785/`

Only `source.png` is copied into the public browser assets. The instructor Word
document and intake report remain in the preserved intake folder and are not
included in the production site.

## Source image

The approved image is an 832 × 1084 PNG created directly from page 414 of the
Google Books scan of J. Collingwood Bruce, *Lapidarium Septentrionale* (1875).
The underlying 1875 illustration is public domain in the United States.

The public copy is byte-identical to the authoritative intake PNG. It has not
been resized, cropped, rotated, recolored, compressed, sharpened, or cleaned.
Small scan and reproduction artifacts remain.

Modern RIB Online catalogue information, edition, translation, and commentary
are attributed separately under the textual-data notice stored in the case
metadata. The public-domain image determination does not rely on a license for
a modern image file.

## Instructor-provided fields

The curated case module stores these instructor-approved fields separately:

- diplomatic transcription using visible inscriptional `V`;
- normalized instructor reading with abbreviation expansion and normalized
  `U`;
- word-segmentation reference without required expansion or normalization;
- instructor translation;
- simplified notation settings;
- public-domain image provenance, credit, and rights notice;
- modern RIB textual and catalogue attribution;
- approved student-facing historical context;
- ordered activity stages and development status.

## Why the case is disabled

This milestone adds permanent assets and metadata only. The case card appears
under **Latin Text Investigations**, but the **In Development** control is
disabled so students cannot enter a partial workflow.

Letter identification is the next activity interface to be built. No
transcription, segmentation, translation, comparison, scoring, machine
learning, or upload interaction is implemented for this case yet.
